# Adult Klauer Trainer

Прототип тренажёра индуктивного мышления для взрослых (6 операций Klauer/Phye-style без копирования исходных материалов).

## Stack
- React + TypeScript + Vite
- TailwindCSS
- Zustand
- localStorage persistence
- Vitest

## Run
```bash
npm install
npm run dev
```

## Tests
```bash
npm run test
```

## Features
- 6 генераторов задач с seed/difficulty/mode
- Адаптивная сложность по операциям
- Режимы: single/mixed/weakness/expert
- Rule journal
- Прогресс по операциям
