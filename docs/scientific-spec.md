# Scientific specification: Adult Klauer Trainer

## Цель
Система тренирует 6 операций индуктивного мышления: обобщение, различение, перекрёстную классификацию, распознавание отношений, различение отношений и построение системы правил.

## Дизайн
1. **Репрезентации стимулов**: visual/symbolic/numeric генерация с контролем признаков и дистракторов.
2. **Адаптация**: отдельный параметр способности на операцию (1..10), обновляемый по успеху/ошибке.
3. **Target success band**: логика прироста/снижения калибруется под 70–80% точность, сохраняя умеренный challenge point.
4. **Нематричный акцент**: только одна операция использует rule-system synthesis; остальные строятся на классификации и отношениях вне Raven-like матриц.
5. **Explanatory feedback**: после ответа выдаётся explanation и ведётся журнал правил.

## Хранимые данные
- ability by operation
- history (correctness + response time)
- rule journal notes
